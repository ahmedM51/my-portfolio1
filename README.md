# My Portfolio

A modern personal portfolio website built with [Next.js](https://nextjs.org/), [React](https://react.dev/), and [Tailwind CSS](https://tailwindcss.com/).

## Features

- Responsive design
- Dark theme UI
- Animated sections
- Projects showcase
- Skills & certifications
- Contact form
- Arabic / English language support

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build

```bash
npm run build
```

## Deployment

This project can be deployed on Vercel, Netlify, or any static hosting provider that supports Next.js.
